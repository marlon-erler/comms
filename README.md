# udn-comms

UDN-Comms is a messenger built for [UDN](https://github.com/marlon-erler/udn).

> [!WARNING]
> Development on this repository has been replaced with [CT](https://github.com/marlon-erler/ct/tree/main).

# Features

- Offline support
- Encryption
- Secondary channels

# Getting Started

1. Use or install the web app [here](https://udn-comms.onrender.com/)
2. Enter your name
3. Connect to your server
4. Create a chat and start messaging
